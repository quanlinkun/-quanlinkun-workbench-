# 2026-08-28 工作日志

## 工作台视觉改造：A 方案「深空粒子流」
- 用户反馈原界面"太过丑陋"，想要动态粒子 + 现代科技感。先给出 4 个方案（A 深空粒子流 / B 玻璃极光 / C 赛博网格 HUD / D 极光流动）并做了带实时 canvas 动画的对比预览，用户选 A。
- 新增 `assets/js/particles.js`（独立模块，不依赖其它脚本）：金色星座连线粒子背景。
  - 粒子数按窗口面积自适应（22–96），手机端（<760px）自动减半
  - `document.hidden` 时跳过绘制以省电；遵循 `prefers-reduced-motion`（默认不启动）
  - `MutationObserver` 监听 `data-theme`，主题切换自动换色（读 CSS 变量 --particle / --particle-rgb）
  - 鼠标 150px 内连线；`localStorage[wb_particles]` 开关；暴露 `window.SpaceParticles.{start,stop,setOn,isOn}`
  - canvas 缺失时静默 return，不报错
- CSS：新增 `[data-theme="space"]` 主题（深蓝渐变底 `#070d1a→#0d1b2a`、半透明玻璃卡片 `rgba(18,31,54,0.72)`、金色描边、浅色文字 `#E6EDF8`）。
  - 把硬编码浅色块（`#fff7d6`/`#fffdf6`/`#f0e2b8`/`#e9dca0`/`#eee`）变量化为 `--soft-bg`/`--soft-bg-2`/`--soft-border`/`--progress-bg`，浅色与深色主题取值保持原样，不受影响
  - space 下金底元素（`.chip`/`.btn.gold`/`.flashcard`）改用深色字 `#2b1f08`，避免浅色文字压在金底上对比度不足
  - space 下侧边栏/顶栏/卡片加 `backdrop-filter` 毛玻璃，粒子可从半透明卡片后透出
- index.html：body 内插入 `<canvas id="spaceCanvas">`（z-index 0、pointer-events none，#app 提为 z-index 1），`particles.js` 在 `app.js` 前加载；`theme-color` 改为 `#0D1B2A`。
- app.js：`initTheme` 默认主题改为 `space`；设置页主题区新增「🌌 深空科技」；新增「✨ 动态粒子」开关卡片与 `toggleParticles()`。原浅色/深色主题保留，随时可切。
- sw.js：缓存版本 v2 → v3，预缓存列表加入 particles.js（保证离线时背景仍能动）。
